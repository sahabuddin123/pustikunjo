# Pusti Kunjo (পুষ্টি কুঞ্জ)

> **Purity Begins here** — ১০০% প্রাকৃতিক, স্বাস্থ্যকর ও নির্ভেজাল পুষ্টি পণ্যের প্রিমিয়াম ই-কমার্স প্ল্যাটফর্ম।

## 🌿 প্রজেক্ট ওভারভিউ (Project Overview)
**Pusti Kunjo** একটি পূর্ণাঙ্গ আধুনিক ই-কমার্স প্ল্যাটফর্ম যা Laravel 12, Inertia.js (React), এবং Tailwind CSS দিয়ে নির্মিত।

### 🌟 প্রধান ফিচারসমূহ (Key Features):
1. **স্টোরফ্রন্ট (Storefront):**
   - আধুনিক রেসপন্সিভ হোমপেজ (ফুল-উইডথ ক্যারোসেল, ভিডিও রিলস গ্রিড, টপ প্রোডাক্ট শোকেস)।
   - ইনস্ট্যান্ট কার্ট ড্রয়ার ও ওয়ান-পেজ দ্রুত চেকআউট (ক্যাশ অন ডেলিভারি এবং বিকাশ সেন্ড মানি)।
   - অটোমেটেড ভেরিয়েন্ট ক্যালকুলেটর (যেমন: 100g, 250g, 500g প্যাকেজ অনুযায়ী ইনস্ট্যান্ট দাম ও ডিসকাউন্ট আপডেট)।
   - লাইভ পার্সেল ট্র্যাকিং (মোবাইল নম্বর ও অর্ডার নম্বর দিয়ে ট্র্যাকিং)।
   - পুষ্টিবিদের পরামর্শ ও হেলথ গাইড ফরম।

2. **এডমিন প্যানেল ও পেজ বিল্ডার (Admin Panel & Dynamic Builder):**
   - **CKEditor-স্টাইল রিচ টেক্সট এডিটর**: ফরম্যাটিং, মিডিয়া লাইব্রেরি ইমেজ ইনসার্ট, টেবিল ও লিংক ইত্যাদি দিয়ে যেকোনো পেজের কনটেন্ট ডাইনামিক এডিট।
   - **ড্র্যাগ-অ্যান্ড-ড্রপ সেকশন বিল্ডার**: হোমপেজ ও স্পেশাল ল্যান্ডিং পেজের ব্লক সাজানো।
   - **অর্ডার ও ফ্রড ট্র্যাকিং (Fraud Checker)**: কাস্টমার সাকসেস রেট, ডেলিভারি রেশিও এবং কালোতালিকাভুক্ত (Blacklist) নম্বর ফিল্টার।
   - **Steadfast কুরিয়ার ইন্টিগ্রেশন**: এক ক্লিকে পার্সেল এন্ট্রি ও ট্র্যাকিং সিঙ্ক।
   - **গ্লোবাল সাইট সেটিংস**: লোগো, মেটা এসইও, এসএমএস গেটওয়ে, বিকাশ এপিআই, ডেলিভারি চার্জ।
   - **মিডিয়া লাইব্রেরি**: ফাইল ও ইমেজ ম্যানেজার।

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)
- **Backend:** Laravel 12 (PHP 8.2+)
- **Frontend:** React 19, Inertia.js v2, Tailwind CSS
- **Icons & UI:** Lucide React
- **Database:** SQLite / MySQL
- **Tooling:** Vite, Composer, NPM

## 🚀 লাইভ সার্ভার অটো ডিপ্লয়মেন্ট (1-Click Live Server Deploy)

লাইভ সার্ভারে (VPS / Ubuntu / Nginx / Apache) প্রজেক্টটি ডিপ্লয় করতে টার্মিনালে শুধু নিচের কমান্ডগুলো চালান:

```bash
git clone https://github.com/sahabuddin123/pustikunjo.git
cd pustikunjo
chmod +x deploy.sh
./deploy.sh
```

> **`deploy.sh` যা যা স্বয়ংক্রিয়ভাবে সম্পন্ন করবে:**
> - `.env` তৈরি ও অপ্টিমাইজেশন
> - `APP_KEY` জেনারেশন
> - SQLite / Database ফাইল প্রস্তুতকরণ
> - Composer প্রডাকশন ডিপেনডেন্সি ইন্সটল
> - Frontend অ্যাসেট বিল্ড (`npm run build`)
> - ডাটাবেস মাইগ্রেশন ও ডিফল্ট ডাটা সিডিং (`migrate & seed`)
> - পাবলিক স্টোরেজ সিম্বলিক লিঙ্ক তৈরি (`storage:link`)
> - ক্যাশ অপ্টিমাইজেশন (`config`, `route`, `view` ক্যাশিং)
> - ফোল্ডার পারমিশন (`775` ও `www-data` ওনারশিপ)

## 💻 লোকাল সেটআপ নির্দেশিকা (Local Setup)

```bash
# ১. ডিপেনডেন্সি ইন্সটল
composer install
npm install

# ২. এনভায়রনমেন্ট কনফিগারেশন
cp .env.example .env
php artisan key:generate

# ৩. ডাটাবেস মাইগ্রেশন ও সিডিং
php artisan migrate --seed

# ৪. অ্যাসেট বিল্ড
npm run build # অথবা ডেভেলপমেন্টের জন্য npm run dev

# ৫. সার্ভার রান
php artisan serve
```
